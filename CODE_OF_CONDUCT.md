# Código de Conducta de Lumina Code

## Nuestro compromiso

Queremos que la comunidad de Lumina Code sea un espacio abierto, respetuoso y útil para personas con distintos niveles de experiencia, identidades, capacidades y contextos culturales.

Participar en este proyecto implica comprometerse a crear una experiencia libre de acoso y a tratar las ideas técnicas con rigor sin deshumanizar a quienes las proponen.

## Comportamientos esperados

- comunicarse con respeto, paciencia y claridad;
- ofrecer críticas específicas, constructivas y centradas en el trabajo;
- aceptar correcciones y reconocer errores;
- respetar límites, privacidad y diferencias de experiencia;
- dar crédito al trabajo y las ideas de otras personas;
- ayudar a que nuevos colaboradores puedan participar;
- priorizar seguridad y bienestar cuando una decisión técnica afecte a usuarios.

## Comportamientos inaceptables

- insultos, amenazas, intimidación o ataques personales;
- acoso público o privado;
- lenguaje discriminatorio o sexualizado no solicitado;
- publicación de información privada sin permiso;
- suplantación, manipulación o atribución deliberadamente falsa;
- sabotaje de discusiones, issues o pull requests;
- presión para revelar credenciales, datos personales o información confidencial;
- cualquier conducta que una persona razonable consideraría hostil o insegura.

## Alcance

Este código se aplica en issues, pull requests, Discussions, revisiones, canales comunitarios y espacios públicos donde una persona represente oficialmente al proyecto.

## Aplicación

Los incidentes pueden reportarse de forma privada a **lessamtv@gmail.com**. Incluye contexto suficiente para revisar la situación, pero no redistribuyas contenido sensible más allá de lo necesario.

El mantenedor revisará los reportes de buena fe y podrá tomar medidas proporcionales, entre ellas:

1. una corrección o advertencia privada;
2. eliminación de contenido inapropiado;
3. restricción temporal de participación;
4. prohibición permanente en casos graves o repetidos.

Se protegerá la privacidad de las personas que reporten un incidente en la medida de lo posible. Las denuncias deliberadamente falsas o usadas para acosar también constituyen una violación de este código.

## Espíritu de la comunidad

Lumina Code se construye alrededor de una idea sencilla: la tecnología debe ayudar sin abandonar la responsabilidad humana. Esperamos lo mismo de la manera en que trabajamos juntos.
